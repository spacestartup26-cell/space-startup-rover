# Space Startup — Rover Game

A simple, responsive project website. The original supplied logo and PowerPoint are included. Three resource links are intentionally marked "Coming soon" until the team provides them.

## Update the links

Open `dist/links.js` and paste the public YouTube, Scratch, and report URLs into the three empty strings. Republish after changing them, or send the links in this Codex chat and ask for an update. Empty or invalid URLs remain disabled; the page does not use fake links.

The PowerPoint download is `dist/assets/rover-presentation.pptx`, an unchanged copy of the team's original 17-slide deck. The original also includes planning material. The website summarizes only the project background.

## Hosting

The live site is hosted with Sites. `.openai/hosting.json` preserves its project identity. The site must have public access so judges can open it without signing in.

For another static hosting service, upload the contents of `dist/` to the hosting root. No installation or build step is needed. `index.html` must be at the root. GitHub Pages is a compatible alternative; NASA's prior official submission guide lists GitHub among example external hosts. Provider compatibility does not guarantee challenge eligibility or project acceptance.
